TeamsSync 利用者マニュアル

TeamsSyncは、CSVまたはExcelの名簿を使って、Microsoft Teamsのチームへメンバーをまとめて追加・削除するアプリです。

このアプリでは、同期を実行する前に変更内容を確認できます。初めて使うときは、削除が発生しない「追加のみ」で試してください。

はじめに確認すること

操作を始める前に、次の点を確認してください。

  • Microsoft 365へサインインできるアカウントが必要です。
  • 操作できるのは、自分が「所有者」になっているチームだけです。
  • メンバー一覧には、できるだけメールアドレスを使用してください。氏名だけでは同姓同名の人を区別できないことがあります。
  • 「完全同期」では、一覧にいない一般メンバーがチームから削除されます。
  • チームの所有者は保護され、一覧に含まれていなくても削除されません。
  • 同期を途中で中止しても、すでに完了した追加・削除は元に戻りません。

重要

初回は「追加のみ（既存メンバーを維持）」を選び、「差分を確認」まで行って、対象チームと追加予定の人が正しいことを確認してください。

用語の説明

用語 このマニュアルでの意味
所有者 チームを管理できる人です。TeamsSyncでは削除対象になりません
一般メンバー 所有者ではないチームメンバーです。追加・削除の対象になります
追加のみ 一覧にいる人を追加し、現在のメンバーは削除しない安全なモードです
指定メンバーを削除 一覧にいる現在の一般メンバーだけを削除し、それ以外のメンバーを維持するモードです
完全同期 一覧とチームを一致させるため、一覧にいない一般メンバーを削除するモードです
差分 同期によって追加・削除される人の一覧です
UPN Microsoft 365へのサインインに使う名前です。通常はメールアドレスと同じような形式です

基本の操作

  1. Microsoft 365へサインインする
  2. 同期先のチームを選ぶ
  3. メンバー一覧を指定する
  4. 同期モードを選ぶ
  5. 差分を確認する
  6. 同期を実行する
  7. 結果とTeams側の最新状態を確認する

1. Microsoft 365へサインインする

画面右上の「サインイン」を押します。ブラウザーが開いたら、チームの所有者になっているMicrosoft 365アカウントでサインインしてください。

サインイン後、そのアカウントが所有しているチームが読み込まれます。

2. 同期先のチームを選ぶ

「1 所有しているチーム」で対象のチームを選びます。入力欄へチーム名の一部を入力すると候補を絞り込めます。

目的のチームがない場合は、次を確認してください。

  1. 検索文字を消すか短くする
  2. 「再読込」を押す
  3. Teamsで自分がそのチームの所有者になっているか確認する

重要

名前の似たチームを選び間違えないよう、同期前の最終確認でもチーム名を確認してください。

3. メンバー一覧を指定する

「2 メンバーリスト」で、「ファイル」または「テキスト貼り付け」を選びます。

ファイルを使う場合

利用できるファイルはCSV（.csv）とExcel（.xlsx）です。古いExcel形式（.xls）には対応していません。

次のような1列の一覧が最も確実です。

メールアドレス
taro.yamada@example.com
hanako.suzuki@example.com
  • 1行目には「メールアドレス」などの見出しを入れます。
  • 2行目以降には1行につき1人を入力します。
  • Excelでは最初のシートを読み込みます。
  • 複数の列がある場合は、メールアドレスまたはUPNの列を氏名列より優先します。
  • 対応する見出しが見つからない場合は1列目を読み込みます。

利用できる主な見出しは次のとおりです。

  • メールアドレス: email、mail、メール、メールアドレス
  • サインイン名: upn、userPrincipalName
  • 氏名: name、displayName、氏名、姓名、名前

ファイルを選んだ後、画面に表示される件数、シート名、採用された列を確認してください。

テキストを貼り付ける場合

「テキスト貼り付け」タブへ、メールアドレスまたは氏名を1行に1人ずつ貼り付けます。その後、「入力を反映」を押してください。

入力内容を変更した場合は、もう一度「入力を反映」を押す必要があります。

現在のチームメンバーを基準にする場合

「現在のメンバーを取り込む」を押すと、選択中チームの一般メンバーを取得し、山田 太郎 <taro.yamada@example.com>の形式で「テキスト貼り付け」タブへ反映します。人物を確認しやすいよう表示名も示しますが、同期の識別には山括弧内のメールアドレスだけを使用します。チームの所有者は入力へ含めません。

既にファイルまたはテキストを指定している場合は、置き換え確認が表示されます。取得失敗、キャンセル、一般メンバーが0人の場合は、現在の入力を維持します。

取り込んだ一覧から数人を追加・削除して「入力を反映」を押すと、現在の構成を基準に完全同期の差分を作成できます。同期モードは自動で変更されないため、目的に合うモードを選んでから「差分を確認」を押してください。

氏名を使う場合の注意

氏名では「山田 太郎」「山田　太郎」「山田太郎」を同じ名前として扱います。同じ氏名の人が複数いる場合は安全のため同期できません。エラーになった行をメールアドレスへ変更してください。

4. 同期モードを選ぶ

追加のみ（既存メンバーを維持）

一覧にいる人を追加します。現在チームにいる人が一覧になくても削除しません。初回や、削除する必要がない場合はこちらを選んでください。

指定メンバーを削除

一覧に入力した現在の一般メンバーだけを削除します。入力していないメンバーとチームの所有者は削除しません。数人だけをまとめてチームから外したい場合に使用します。

入力した人が現在チームに所属していない場合は「未所属」と表示され、追加も削除も行いません。同じ氏名の人が複数いる場合やユーザーを特定できない場合は、同期を実行できません。

完全同期（リスト外を削除）

一覧にいる人を追加し、一覧にいない一般メンバーを削除します。チームの所有者は削除しません。

たとえば、現在の一般メンバーが「Aさん、Bさん、Cさん」で、一覧が「Aさん、Dさん」の場合は、Dさんを追加し、BさんとCさんを削除します。

重要

完全同期を選ぶ前に、そのファイルが「追加したい人だけの一覧」ではなく、「同期後に残したい一般メンバー全員の一覧」であることを確認してください。

同期モードを変更すると、以前に確認した差分は消去されます。もう一度「差分を確認」を押してください。

5. 差分を確認する

「差分を確認」を押すと、実際に行われる変更が一覧に表示されます。

表示 意味 確認すること
追加 チームへ追加する人 人物とメールアドレスが正しいか
削除 チームから削除する一般メンバー 本当に削除してよいか
変更なし すでにチームにいる人 通常は対応不要です
保護 チームの所有者 削除されません
未所属 指定削除の入力に含まれるが、現在はチームにいない人 追加も削除もされません
エラー 人を特定できなかった入力 メールアドレスへ直すなどして解消します

「表示」から、追加のみ、削除のみ、エラーのみなどへ絞り込めます。列見出しを押すと並べ替えられます。

エラーが1件でもある場合は同期を実行できません。入力を修正して読み込み直し、もう一度差分を確認してください。

6. 同期を実行する

差分を確認したら「同期を実行」を押します。最終確認画面で、次の項目をもう一度確認してください。

  • 対象チーム
  • 同期モード
  • 入力元
  • 追加人数
  • 削除人数

削除がある場合は、削除対象の人数が警告表示されます。内容を確認したうえで「同期を実行」を押してください。

同期中は進み具合と現在処理している人が表示されます。「キャンセル」またはEscキーで中止できます。

重要

中止するまでに完了した追加・削除は元に戻りません。中止後は必ず、もう一度「差分を確認」を押してTeams側の最新状態を確認してください。

7. 結果を確認する

同期後、画面下部のメッセージと差分一覧を確認します。

  • すべて成功した場合: Teams側の状態が再確認され、残りの差分がなければ完了です。
  • 一部失敗した場合: 成功した変更はそのまま残ります。画面に表示された未反映件数を確認し、必要に応じて再実行します。
  • 中止した場合: 処理済み件数を確認し、改めて「差分を確認」を押します。
  • 最新状態を確認できなかった場合: 通信を確認してから「差分を確認」を押します。

「結果を保存」を押すと、今回実行した各操作の成功・失敗をCSVへ保存できます。画面の一時通知を見逃した場合も、画面下部のメッセージと最新の差分を確認してください。

一部失敗・中止後の安全な再実行

  1. 対象チームと入力一覧を変更しない
  2. 「差分を確認」を押してTeams側の最新状態を取得する
  3. 追加・削除・エラーの件数を確認する
  4. 失敗した人だけが未反映として残っていることを確認する
  5. 内容が正しい場合だけ、もう一度同期を実行する

すでに成功した追加を二重に実行したり、削除済みの人を再度削除したりしないよう、再実行前には必ず差分を作り直してください。

通信エラーと自動再試行

一時的な混雑や通信障害では、アプリが短時間待って通信を自動的にやり直すことがあります。この動作に利用者の操作は必要ありません。

自動再試行を行っても失敗した操作は、結果で「失敗」または「未反映」として扱われます。その場合は、通信状態を確認し、「差分を確認」で最新状態を取得してから再実行してください。

よくあるトラブル

表示・状況 主な原因 利用者が行うこと
サインインできない アプリ設定、組織の利用許可、管理者同意の不足 Microsoft 365管理者へ画面のエラーを伝える
チームが一覧にない 所有者ではない、一覧が古い、検索で隠れている 検索を消して再読込し、Teamsで所有者か確認する
ファイルを読み込めない 非対応形式、開けないファイル、内容の問題 .csvまたは.xlsxか確認し、ファイルを開けるか試す
読み込まれた列が違う 見出しが認識されず1列目が選ばれた メール列の見出しを「メールアドレス」へ変更する

同期を実行できない 差分未確認、エラーあり、変更なし、別処理中 画面下部の説明を確認し、必要な操作を行う

管理者へ問い合わせるときは、次の情報を伝えてください。

  • 発生した日時
  • 対象チーム名
  • 画面に表示されたエラーメッセージ
  • 同期結果CSV（保存できる場合）

パスワードやサインイン画面の認証情報は共有しないでください。

キーボード操作

TabキーとShift+Tabキーで、画面内の主な操作へ順番に移動できます。同期中はEscキーでキャンセルできます。
