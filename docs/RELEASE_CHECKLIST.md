# TeamsSync リリース前チェックリスト

## 自動確認

- [ ] `task build`が警告・エラーなしで成功する
- [ ] `task test`が全件成功する
- [ ] `dotnet list TeamsSync.slnx package --vulnerable --include-transitive`で未対応の既知脆弱性がない
- [ ] `dotnet list TeamsSync.slnx package --outdated`の結果を確認する
- [ ] `task publish-single`が成功し、成果物が起動する

## 非本番テナント

- [ ] 対象テナントとサインイン中アカウントが正しい
- [ ] 所有しているチームだけが一覧へ表示される
- [ ] CSV、Excel、貼り付け入力から差分を作成できる
- [ ] 追加のみモードで既存メンバーが削除されない
- [ ] 完全同期で一般メンバーを追加・削除できる
- [ ] 所有者が削除対象にならない
- [ ] 未解決ユーザーがある場合に同期できない
- [ ] 大量削除の警告と確認チェックが表示される
- [ ] 部分失敗後に最新状態を取得し、未反映分だけ再実行できる
- [ ] 権限不足と管理者同意なしのエラーを利用者が識別できる

## UI・アクセシビリティ

- [ ] 1024×768および表示倍率125%、150%、200%で主要操作が画面外へ隠れない
- [ ] TabとShift+Tabだけで主要操作へ移動できる
- [ ] Narratorで入力、差分、警告、進捗、主要ボタンを識別できる
- [ ] ハイコントラストモードで文字、フォーカス、警告を識別できる
- [ ] 操作種別を色だけでなく文言でも識別できる
- [ ] 同期中にEscapeでキャンセルし、完了を待って終了できる

詳細は[アクセシビリティ確認](../ACCESSIBILITY.md)を参照してください。

## 配布・運用

- [ ] バージョン番号とリリースノートを更新する
- [ ] Entra IDのClientId、TenantId、必要権限を確認する
- [ ] 成果物をコード署名し、署名とタイムスタンプを検証する
- [ ] 監査ログの保存先、保持数、アクセス権を確認する
- [ ] ロールバック用に直前の署名済み成果物を保持する
- [ ] 配布後にサインイン、ファイル読込、同期プレビューのスモークテストを行う
